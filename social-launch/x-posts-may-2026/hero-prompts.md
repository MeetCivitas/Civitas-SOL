## How to use

1. Open a fresh **regular** ChatGPT chat (not Temporary — Temporary doesn't allow image generation).
2. Paste each prompt above.
3. Pick the best of the two images ChatGPT returns.
4. Right-click → Save Image → name it exactly `dayNN-XX.png` (matching the heading above).
5. Place in `social-launch/x-posts-may-2026/images/`.
6. Re-run `node schedule-all.mjs` and it'll pick up the new heroes automatically.

If you don't want to bother — the text-card version (`render-cards.mjs`) already covers every post. Hero images are upgrades, not requirements.
